= Rivu

Rivu is a lightweight, local-first music player for Linux.

* Local library, playlists, favorites, queue control, and play counts
* Desktop GUI, CLI, TUI, and MPRIS controls
* Movable TokyoNight workspace and audio visualizations
* Audio-only playback, including CUE subtracks

== Build and install

[source,sh]
----
sudo pacman -S --needed rust pkgconf alsa-lib libpipewire clang ffmpeg opus fontconfig libxkbcommon
cargo build --release
make install PREFIX="$HOME/.local"
----

The default GUI targets Wayland. Ensure `~/.local/bin` is on `PATH`.

== Run

[source,sh]
----
rivu gui ~/Music
rivu serve ~/Music
rivu tui
rivu --help
----

`gui` and `serve` each start a core; do not run both against the same data
 directory. Use the CLI or TUI to control an existing instance.
