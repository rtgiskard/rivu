= Rivu

Rivu is a lightweight, local-first music player for Linux.

* Local library, playlists, favorites, queue control, and play counts
* Desktop GUI, CLI, TUI, and MPRIS controls
* Movable TokyoNight workspace and audio visualizations
* Audio-only playback, including CUE subtracks

== Build and install

[source,sh]
----
sudo pacman -S --needed rust pkgconf alsa-lib libpipewire clang ffmpeg opus fontconfig libxkbcommon
cargo build --release
make install PREFIX="$HOME/.local"
----

The default GUI targets Wayland. Ensure `~/.local/bin` is on `PATH`.

== Run

[source,sh]
----
rivu gui ~/Music
rivu serve ~/Music
rivu tui
rivu --help
----

`gui` starts a core when none is running. Running `rivu gui` again against the
same data directory focuses its window or recreates it without restarting playback.
`serve` starts a headless core; it cannot open a GUI window. Use the CLI or TUI
to control an existing instance.

Closing the GUI window does not stop playback. The core, MPRIS service, and GUI
host keep running without a hidden window. Reopen with `rivu gui` or MPRIS Raise;
the queue and playback position are retained. Use `rivu quit` or MPRIS Quit to
stop the core and GUI host.
