= Configuration and workspace

The default configuration file is `~/.config/rivu/config.toml`.

[source,toml]
----
media_read_buffer_mb = 2
ffmpeg_enabled = false
pipewire_auto_mix = true
tray_enabled = true
mpris_enabled = true
ui_font = ""
play_count_threshold_percent = 20.0
spectrogram_db_range = 70.0
spectrum_db_range = 70.0
spectrogram_interpolation_points = 1024
spectrogram_history_seconds = 30
----

Spectrogram interpolation generates logarithmic frequency rows up to the configured point count (64–4096); the default is 1024. The row count is also limited by the panel's rendered height. Spectrogram history grows with continuous audio up to `spectrogram_history_seconds` (1–120 seconds; default 30).

Accepted media read buffer sizes are `1`, `2`, `4`, `8`, and `16` MiB.

`ffmpeg_enabled` is available at runtime only in a binary built with Cargo's
`ffmpeg` feature (`cargo build --features ffmpeg`). In a default build the
setting remains off and enabling it is rejected with the extension-unavailable
error; native decoders continue to work.

`play_count_threshold_percent` must be finite and in `[0, 100)`; zero still requires
some confirmed heard time. Edit it in the configuration file or GUI preferences.

`pipewire_auto_mix` allows PipeWire to remix or downmix channels when enabled;
it defaults to `true`. Disable it to require an explicit compatible speaker layout
and reject routes that would lose or remix source channels. The settings panel
contains the same switch.

`tray_enabled` controls creation of the desktop StatusNotifier tray. It defaults
to `true`; disabling it removes the local tray without affecting playback, the
GUI host, or MPRIS.

== Desktop settings

The bottom-right gear opens settings. Library roots are separated by semicolons;
the output device is selected from a dropdown. General and Visualizations are
separate pages, and visualization settings are grouped by view.

`ui_font` accepts a font family name; an empty value uses the platform UI font.
Apply validates and saves the complete draft. Discard closes the dialog and drops
unapplied changes. Saving library roots does not scan them or enqueue tracks; use
`Scan paths` in Library to start a scan.

Closing the GUI window releases window resources but keeps the core and playback
running. The tray, when enabled and available, can show the window, control
playback, and quit Rivu. MPRIS is independent of the tray. `rivu gui` recreates
the window; `rivu quit`, tray `Quit Rivu`, MPRIS `Quit`, or explicit application
quit shuts down the process.

`serve` has no graphical host or tray. CLI, TUI, and MPRIS can still control it.

== Workspace

The desktop workspace is persisted as `workspace.json`, including panel layout,
split ratios, tab order, tab-bar visibility, and the workspace lock. While unlocked,
panels can be added, removed, moved, resized, and reordered. Right-click a panel
to toggle its tab bar; right-click the bottom-right workspace button to toggle
the lock, or left-click it to add a panel. Playback and tab selection remain
available while locked.

Errors and scan progress appear in the footer. Click a message or its copy icon
to copy the complete text.

The Waveform panel shows a whole-track timeline, including CUE boundaries. It
builds a progressive preview from playback PCM, leaves unknown intervals blank,
and stores at most 1600 peak bins. `Load full waveform now` starts an asynchronous
whole-file scan. Source changes cancel obsolete work; hiding a panel does not.

`visual_palette` controls the Waveform palette and accepts `tokyo_night` or
`deadbeef`; the default is `deadbeef`.

The Waveform panel uses the conventional stereo layout: playback time advances
from left to right, the logical left channel is drawn above the centerline, and
the logical right channel below it. The filled body is RMS amplitude; the thin
outer line is the retained peak. Gradients grow from the centerline toward the
outer edge, so the center-to-edge color progression represents amplitude rather
than time. The RMS underlay uses a reduced palette scale; each retained peak is
submitted as its own 1 px shape and receives an independent amplitude color.
The high end is gently compressed so red remains an accent for loud peaks
instead of dominating ordinary loud passages. The palette is shared by both
channels; channel identity comes from its position, not from a red/blue color
convention.

Decoded channels are folded into two logical channels using their speaker
layout. Left-positioned speakers contribute to left, right-positioned speakers
to right, and center/LFE channels contribute to both. Mono audio is calculated
once and mirrored. A shared peak scale preserves the left/right balance.
Unknown timeline intervals remain blank; decoded silence remains visible as a
zero-amplitude region.

The Waveform view has no numeric vertical-axis tick labels. Its vertical scale is
normalized to the shared retained peak: the centerline is zero amplitude and the
outer edge is `1.0` (the loudest decoded logical-channel peak for the track).
`L` and `R` are conveyed by the upper/lower channel placement rather than by a
separate color or numeric axis.

The playback cursor is a water-drop marker centered on the stereo midline. Its
small vertical motion follows a slow, eased periodic curve with deliberate
rhythm rather than a fast jitter. A thin waterline runs above and below the
marker, leaving the drop unobstructed; its x-position remains aligned to the
selected time. Click or drag across the actual waveform plot to seek the current
track; positions outside the plot are clamped to the track endpoints. Dragging
a non-playing selection preview does not issue a playback seek.

=== Spectrum and Spectrogram

Spectrum displays width-aware musical bands with configurable styles, peak hold,
and smoothing. Spectrogram displays frequency over time with a separate history
range. Both views follow the source Nyquist limit and configured frequency range.

The three visualizations share `visual_background` and `visual_palette`. The
default background is `#08090c`; palette `a` is TokyoNight and `b` is the
DeaDBeeF-inspired gradient. `analysis_fps` accepts 5–60 updates per second.
Changing visual settings redraws the views without decoding the track again.

Spectrum's independent settings are:

* `spectrum_style`: `bars` (default), `outline`, `led`, `line`, or `solid`.
  These draw filled bars, outlined bars, segmented LED bars, a connected line,
  or a filled continuous spectrum. Style changes also redraw a paused frame.
* `spectrum_min_hz` / `spectrum_max_hz`: frequency interval, default 20–20000 Hz.
* `spectrum_db_range`: amplitude span, 1–160 dB, default 70.
* `spectrum_fft_size`: 512, 1024, 2048, 4096, 8192 (default), 16384, or 32768.
* `spectrum_window`: `hann`, `blackman_harris` (default), or `none`.
* `spectrum_bands_per_octave`: 1–48, default 24.
* `spectrum_bars`: `0` (automatic) or 1–512; narrow panels cap the count.
* `spectrum_bar_width`: 1–20 pixels, default 3, controls automatic density.
* `spectrum_gap`: 0–8 pixels, default 1, reduced to keep bars visible.
* `spectrum_interpolate` and `spectrum_log_scale`: enabled by default.
* `spectrum_peaks`: peak markers, enabled by default.
* `spectrum_peak_hold_ms`: 0–2000 ms; default 400.
* `spectrum_bar_hold_ms`: 0–2000 ms; default 0.
* `spectrum_peak_gravity` / `spectrum_bar_gravity`: 0–500 dB/s², default 50.
  These accelerate the fall after the hold; zero snaps to the current level.
* `spectrum_smoothing_ms`: 0–1000 ms, default 80, smooths release while retaining
  immediate attacks. Motion follows audio time and freezes while paused.
* `spectrum_grid`: faint horizontal references, independent of labels.
* `spectrum_labels`: axis labels, enabled by default; bottom frequencies show only
  the two endpoints, never a midpoint.

=== Radial Spectrum control

The workspace catalog contains a separate `Radial Spectrum` control. Its mode
and presentation parameters are explicitly based on Noctalia Shell v5's Fancy
Audio Visualizer control, especially the mirrored spectrum and ring settings:

* https://github.com/noctalia-dev/noctalia-shell/blob/e56a9db5/Widgets/AudioSpectrum/NMirroredSpectrum.qml[`NMirroredSpectrum.qml`]
* https://github.com/noctalia-dev/noctalia-shell/blob/e56a9db5/src/shell/bar/widgets/audio_visualizer_widget.cpp[`audio_visualizer_widget.cpp`]

Rivu reuses the shared live FFT and implements the `bars`, `rings`, and combined
`bars_rings` modes with GPUI-native paths. The parameter model is based on the
Noctalia v5 control; geometry, compositing, and glow rendering are adapted to
Rivu's renderer and are not a pixel-identical QML port.

The control settings are:

* `radial_spectrum_style`: `bars`, `rings`, or `bars_rings` (default
  `bars_rings`).
* `radial_spectrum_sensitivity`: 0–5, default 1.5; gain applied to normalized
  FFT levels before drawing.
* `radial_spectrum_rotation_speed`: 0–10, default 0.5; animation phase speed.
* `radial_spectrum_bar_width`: 0–2, default 0.6; angular bar width in Bars
  mode.
* `radial_spectrum_bar_glow_layers`: 0–4, default 2; number of translucent
  halo passes around each active Bar. Zero disables Bar halos without disabling
  Ring Bloom.
* `radial_spectrum_ring_opacity`: 0–1, default 0.8.
* `radial_spectrum_bloom_intensity`: 0–2, default 0.5; controls Ring halos and
  Bar halo opacity.
* `radial_spectrum_primary_color` / `radial_spectrum_secondary_color`:
  `#RRGGBB` endpoints, default `#7aa2f7` and `#bb9af7`.

Bars mirror normalized FFT bands around a circular baseline. Rings use the same
values for segmented, rotating circular accents and amplitude-driven inner and
outer rings. `bars_rings` draws both presentations. Spectrum settings such as
`spectrum_db_range` still provide the shared amplitude range; changing these
settings redraws the control without decoding the track again.

Spectrogram display settings are:

* `spectrogram_db_range`: independent color span, 1–160 dB, default 70.
* `spectrogram_history_seconds`: maximum continuous audio history, 1–120 seconds,
  default 30. The visible window grows with available uninterrupted audio and
  remains blank where no history exists.
* `spectrogram_labels`: show endpoint frequency labels, default true.
* `spectrogram_interpolate`: interpolate dB values at logarithmic frequency positions
  before color mapping, default true. Disable it to use nearest source frequency points.
* `spectrogram_interpolation_points`: maximum frequency rows per cached column,
  64–4096, default 1024. The source row count follows the tallest active
  Spectrogram panel and is capped by this setting; smaller panels scale it down.

The frequency axis is always logarithmic from 16 Hz to the source Nyquist limit.
Rendering clips the fixed range to available analyzer bands; empty intersections
report an error instead of relabeling unrelated data.
Spectrum permits headroom above 0 dB; Spectrogram colors span its negative dB
range through 0 dB. The heatmap has no reference lines and labels only its endpoints.

`waveform_cursor_color` defaults to `#73daca`; `waveform_glow` accepts 0–2
(default 1). `waveform_labels` controls endpoint time labels and defaults to true.
Appearance changes reuse decoded preview data. Visual Boolean settings use
highlighted icon switches with explanatory On/Off tooltips.

Apply validates and saves all pages together; navigating between pages preserves
the draft. Display-only changes do not reopen the decoder or audio output.

`nerd_symbols` defaults on only when installed Nerd Font families are detected
through fontconfig. Detection is cached; a missing detector or no matching fonts
defaults it off. A saved explicit preference takes precedence. The General page
provides a Nerd Symbols switch; non-Nerd symbols remain usable when disabled.

== Visual assets

`assets/rivu.svg` is the vector application icon and `assets/rivu.png` is its
256×256 raster export. The playback panel draws the generated fallback artwork;
embedded artwork from supported native media is cached under `artwork/`.

To regenerate the application icon PNG after editing the SVG source (requires
librsvg):

[source,sh]
----
rsvg-convert -w 256 -h 256 -o assets/rivu.png assets/rivu.svg
----
