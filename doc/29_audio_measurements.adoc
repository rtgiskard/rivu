== Recorded local evidence and remaining limits

These are earlier local observations, not current-source reruns, universal
performance guarantees or listening approval. Paths below identify task artifacts
under `.cache/`, not installed files. Several quality/GUI/graph bundles, including
`eq-candidate.json`, `audio-quality-corpus/`, `neural/acceptance-evidence/` and
`audio-graph-evidence/`, are absent from the current local archive. Check artifact
availability and source identity before reusing any record for acceptance.

Human listening, quiet-content/stereo-artifact approval, broad lossless fullband
music coverage and device-specific underrun/deadline evidence remain gaps.
Reference parity, scalar improvement and reconstruction do not close them.

=== Native ONNX speech integration checks

Recorded synthetic comparisons used ONNX Runtime 1.23.2 CPU with the pinned
GTCRN and UL-UNAS graphs and an independent Torch STFT/ISTFT reference using
the same complete-hop reflection. Short inputs and partial final hops were
included. UL-UNAS's log-magnitude features amplify FFT roundoff near zero:
its constant one-sample extension differed by 6.39e-4, while feeding the exact
Rust spectrum to the Python runtime reduced the difference to 7.4e-11. This
distinguishes transform conditioning from model execution; it does not justify
input special cases or establish speech quality, listening acceptance or
cross-runtime bit equality. These observations are not acceptance of the current
standalone or graph dispatch paths.

=== Node graph measurements

`audio-graph-evidence/graph-baseline.json` and `graph-optimized.json` recorded
nine repetitions for each of 18 native graph workloads, excluding preparation,
copying, file I/O and device output. Untimed output comparisons were sample-exact
and processing allocated no additional storage. Timings did not show a uniform
speedup or establish physical-device deadlines.

`neural/graph-backend-evidence/comparison.json` covered three seconds of a MUSDB
AAC excerpt with Kim. Its mixture reconstruction checks the accompaniment
definition; one timing run is not a repeated performance estimate, quality ranking
or fullband/listening acceptance.

=== Implementation cost audit

Earlier records in `experiments/audio/classical-audit/`,
`experiments/audio/audio-implementation-audit/`, `audio-review-next/` and
`speech-optimize-20261023/` isolate native allocation, shared worker storage and
MossFormer2 numerical-processing costs. They do not measure whole-process RSS,
model-weight equivalence or device deadlines. Paired numerical checks preserved
outputs within their stated precision; timing did not establish a stable speedup.
Torch/Kaldi/DSP checks did not execute model weights or CUDA. Real-model regression
checks still require prepared manifests and matching interpreters; skipped tests
and environment-installation failures are not passes.
