= Configuration and layout

Rivu reads `~/.config/rivu/config.toml` by default; path overrides are described in
link:../readme.adoc[the README]. Omitted fields use defaults. A minimal example:

[source,toml]
----
library_roots = [] # Add music-directory paths before scanning
scan_max_depth = 64
queue_limit = 4096
page_size = 64
media_read_buffer_mb = 2
ffmpeg_enabled = false
pipewire_auto_mix = true
still_mode = false
tray_enabled = true
mpris_enabled = true
log_level = "warning"
log_to_file = false
log_retention_weeks = 4
----

`library_roots` defaults to an empty list; add existing directories before
scanning. `scan_max_depth` defaults to `64` and must be at least `1`. See
link:02_library.adoc[Library] for root normalization, scan boundaries, and CUE/path
rules.

`queue_limit` accepts `1`–`4096`; lowering it below the current queue length is
rejected. `page_size` accepts `20`–`256` and tunes internal GUI/TUI query batches,
not visible pages or CLI listing/export batches. Browsing scrolls continuously;
query batch tuning stays in the configuration file, not desktop settings. Queue behavior is described in
link:04_playback.adoc#_queue[Playback]; query and batch contracts in
link:02_library.adoc#_paged_views[Library].

Accepted media read buffer sizes are `1`, `2`, `4`, `8`, and `16` MiB.

`ffmpeg_enabled` is available only when the binary includes the `ffmpeg` feature;
see link:../readme.adoc[README] for build variants. In a default build the
setting remains off and enabling it is rejected with the extension-unavailable
error; native decoders continue to work.

`play_count_threshold_percent` must be finite and in `[0, 100)`; zero still requires
some confirmed heard time. Edit it in the configuration file or GUI preferences.

`pipewire_auto_mix` controls channel remixing; see link:04_playback.adoc[Playback].
`tray_enabled` and `mpris_enabled` independently control desktop integration.

`log_level` accepts `debug`, `info`, `warning`, or `error`. Warnings and errors
always go to stderr. `log_to_file` enables weekly logs under the data directory;
`log_retention_weeks` accepts `1`–`520`. `NO_COLOR` or `RIVU_COLOR=never` disables
stderr colors.

The complete field set, defaults, and validation are in
link:../src/config.rs[`Config`]; log handling is in link:../src/logging.rs[logging].

== Desktop settings

Open Settings from the application menu. Separate library roots with semicolons.
In an open dropdown, Up/Down moves the highlight with wraparound;
PageUp/PageDown moves by the visible row count and clamps at the first or last
option without scrolling the settings underneath. Enter or Space accepts an
option in non-editable dropdowns, and Escape closes the dropdown.
The system tray switch takes effect after restarting the graphical host, not
merely reopening its window. Media read buffering applies to future source opens,
including full waveform scans; it does not reopen the current track.
Still mode is under Visualizations → Common → Rendering and takes effect when
settings are applied, without restarting playback. It is persisted as `still_mode`.

General groups controls into Library, Playback, Audio, Interface, Desktop
integration, and Logging. Labels name the setting and its unit; nearby hints
give ranges, special values, or when changes take effect. Shared rules appear
once per group. Configuration keys, defaults, and validation are unchanged.

Visualizations is grouped by view, with shared controls in Common:

* Appearance: background for all views; color scheme for Spectrum, Spectrogram,
  and Waveform. Radial Spectrum has independent primary and secondary colors.
* Default display range: `visualization_db_range` supplies the display span for Spectrum,
  Spectrogram, and Radial Spectrum unless a view overrides it. It belongs to
  Appearance, not frequency analysis, and does not affect Waveform gain or volume.
* Frequency analysis: FFT size, window, and analysis rate for Spectrum,
  Spectrogram, and Radial Spectrum, not Waveform. FFT size defaults to `8192`;
  configuration keys remain `spectrum_fft_size` and `spectrum_window`. Changing
  size or window clears Spectrogram history.
* Rendering: Still mode pauses visualization processing. Rendering cache
  (`visualization_cache`) reuses derived graphics in Spectrum, Spectrogram, and
  Waveform, trading memory for less CPU work; it is separate from media read buffering.

Each frequency view has a range override; leave it empty to inherit Common,
or clear an explicit value to restore inheritance. See
<<_visualization_db_ranges,Visualization dB ranges>> for the configuration contract.

Spectrum groups controls into Appearance, Bar motion, and Peak markers;
Spectrogram uses Display and Frequency sampling; Waveform uses Appearance &
interaction and Amplitude display. Radial Spectrum keeps Shape & motion,
Bars & rings, and Colors.

Style-dependent fields preserve their values while inactive. Hover an inactive
field for the reason; switch back to a compatible style to resume editing.

Font: type to search installed families, or use the arrow to browse them and
`serif`, `sans-serif`, and `monospace`. Enter or a click selects a choice; Space
remains text. Custom family names are accepted.

`ui_font`: empty/System default uses the platform UI font. Nonempty values use
Fontconfig system and user rules (`~/.config/fontconfig/fonts.conf`) to select
the primary family. Missing glyphs use native fallback, which does not guarantee
Fontconfig's custom fallback order. Restart the GUI after changing Fontconfig rules.

GPUI selects faces within each family and renders through cosmic-text/Swash;
Fontconfig hinting, subpixel, and synthetic-bold settings do not apply.

`ui_scale` accepts `0.75`–`2.0`.
Omitted `nerd_symbols` follows installed Nerd Font detection; an explicit value
overrides it. Omitted `output_device` uses the default output; a selected device
must be available.

`library_tree_lines` defaults to `true`: Library uses thin hierarchy connectors
instead of disclosure arrows. Set it to `false` for arrows without connectors.
The same switch is under General → Interface (`Library tree lines`). Apply
updates the tree immediately without changing expansion or selection.

Apply validates and saves all pages together; navigation preserves the draft.
Discard drops unapplied changes. Saving library roots does not scan or enqueue
tracks; use `Scan paths` in Library. Display-only changes do not reopen audio.
Hover an error to read its complete message, or click its copy icon to copy it.

See link:../readme.adoc[README] for application lifecycle and host behavior.

== Layout

The desktop layout is persisted as `layout.json` in the data directory,
including panel layout, split ratios, tab order, tab-bar visibility, and the
layout lock. While unlocked, panels can be added, removed, moved, resized,
and reordered. Right-click a panel to toggle its tab bar; right-click the
bottom-right layout button to toggle the lock, or left-click it to add a
panel. Playback and tab selection remain available while locked.

Errors and scan progress appear in the footer. Click a message or its copy icon
to copy the complete text.

== Visualization dB ranges

`visualization_db_range` defaults to `70` dB. The optional `spectrum_db_range`,
`spectrogram_db_range`, and `radial_spectrum_db_range` override it only for their
named view. Every supplied range must be finite and between `1` and `160` dB,
inclusive. An explicit override remains an override even if it equals Common's
current value; changing Common later affects only views without overrides.

In TOML, omit a view's override key to inherit Common. Do not write an empty
string or a blank assignment: overrides are numeric when present. Saving an
inherited range omits that override key.

[source,toml]
----
visualization_db_range = 80.0
spectrum_db_range = 60.0
radial_spectrum_db_range = 100.0
# spectrogram_db_range is omitted, so Spectrogram uses 80 dB
----

These ranges affect display mapping only, not FFT analysis, decoded audio,
playback volume, or Waveform's RMS/Peak gains. Spectrogram recolors retained
history without discarding it. Changing an unused Common default or setting an
override equal to the current resolved value leaves the display unchanged.

== Visualizations

Live FFT analysis runs during playback only when Still Mode is off, the
application window is visible, and a Spectrum, Spectrogram, or Radial Spectrum
panel is visible.
`analysis_fps` accepts `5`–`60`; all views use `visual_background`.
`visual_palette` accepts `tokyo_night` or `deadbeef` (default `deadbeef`) and is
shared by Spectrum, Spectrogram, and Waveform. Defaults and accepted ranges are
in link:../src/config.rs[`Config`].
`visualization_cache` defaults to `true`; disabling it preserves the displayed
results but rebuilds derived graphics on repaint. It does not affect Radial
Spectrum. See link:22_cache.adoc[Visualization Cache] for scope and trade-offs,
and link:23_visuals.adoc[Visualization Rendering Design] for rendering choices.

=== Still Mode

`still_mode` defaults to `false`. Enabling it replaces all four visualization
views with a static status, stops analysis sampling and FFT work, and removes
the GUI's analysis-rate refresh timer. Progressive waveform statistics stop;
any running full-waveform request is cancelled, and new requests are unavailable.
Display caches and Spectrogram history are released through their normal image
lifecycle. Small bounded analysis buffers and base waveform data remain retained.

Playback, seeking through the playback slider, ordinary interface effects,
library operations, covers, IPC, MPRIS, and the tray are unchanged. Layout and
visualization settings are preserved, including `visualization_cache`.

Disabling Still Mode resumes the visible views from newly published analysis
without reopening audio output or the decoder. Spectrogram history starts fresh.
Skipped waveform intervals are not filled retrospectively, and an interrupted
traversal is not marked complete. Cancelled full-waveform requests do not restart
automatically; request one explicitly after leaving the mode if needed.

=== Waveform

Waveform shows a whole-track timeline, relative to the subtrack for CUE. Left is
above the centerline, right below; the filled body is RMS amplitude and the outer
line is peak amplitude. Unknown intervals remain blank. Playback builds the
preview progressively; `Load full waveform now` requests the complete preview.
Click or drag to seek the current track; a non-playing selection preview does
not seek playback.
`waveform_seek_enabled` defaults to `true`. Disable Click and drag to seek in
the Waveform settings page or its panel right-click menu to prevent accidental
seeks. Disabling it cancels any active waveform drag and preview; the playback
slider remains available.

RMS uses a center-to-edge palette gradient; Peak uses the palette color at its
level. Known silence remains visible as a minimum-height RMS fill; unknown
intervals stay blank.

`waveform_labels`, `waveform_cursor_color`, and `waveform_glow` control labels,
cursor, and glow. The Amplitude display group exposes `waveform_rms_gain`
(`0`–`3`, default `1.6`), `waveform_peak_gain` (`0`–`2`, default `0.75`), and
`waveform_peak_gamma` (`0.25`–`3`, default `1.1`). Gamma above `1` reduces low
peaks; below `1` lifts them. These controls affect rendering only, not playback
volume or decoded preview data.

=== Spectrum and Spectrogram

Spectrum shows current frequency energy. `spectrum_style` accepts `bars`,
`outline`, `led`, `line`, or `solid`; the remaining `spectrum_*` settings control
FFT resolution/window, band density, spacing, peak hold, release motion, and labels.
Motion freezes while paused.

`spectrum_interpolate` controls frequency interpolation and whether `solid` has a
continuous or stepped boundary. `line` always connects valid body points
continuously and skips empty slots rather than drawing them at the floor.
Peak indicators remain discrete in every style.

Spectrogram shows recent frequency history; `spectrogram_*` settings control its
history duration, color range, labels, interpolation, and the `0.4`–`1.4`
`spectrogram_sampling_points_scale` used to choose source frequency rows. Retained
history also depends on panel width and analysis rate; unavailable history stays blank.
`spectrogram_interpolation_points` defaults to `1024`; the settings page labels
it Maximum frequency rows. This rendering row limit applies with or without
frequency interpolation; it is not the FFT size, and increasing it does not add
measured frequency detail.
Both views use a logarithmic frequency axis and share `spectrum_fft_size` and
`spectrum_window`. Their independent `spectrum_db_range` and
`spectrogram_db_range` overrides inherit `visualization_db_range` when omitted;
see <<_visualization_db_ranges,Visualization dB ranges>>.

=== Audio Visualizer

`radial_spectrum_style` selects the Audio Visualizer presentation:

* `bars`, `rings`, and `bars_rings` use the radial Spectrum presentation.
  Sensitivity, rotation, bar width/glow, ring opacity/Bloom, inner diameter,
  and idle fade apply to these styles only.
* `stereo_density` shows a Mid/Side occupancy field: horizontal Side `(L−R)/2`,
  vertical Mid `(L+R)/2`, both fixed at ±1 without automatic gain. Equal channels
  form a vertical trace; opposite channels form a horizontal trace. Its readout
  reports correlation, left/right energy balance, and the Side share of energy
  over the current FFT window. Correlation is undefined for silence or a silent
  channel. Color represents decaying sample occupancy in dB, not audio dBFS.
* `spatial_spectrum` shows logarithmic frequency vertically and left/right
  energy balance horizontally, with color representing frequency-bin power in
  dBFS. Equal-energy channels appear at the center even when their phases differ;
  this is not a source-direction or phase measurement.

All styles share `spectrum_fft_size`, `spectrum_window`, `analysis_fps`, and the
 two `radial_spectrum_*_color` endpoints. `radial_spectrum_db_range` inherits
`visualization_db_range` when omitted; it controls color mapping, not playback
volume or measured amplitude. The two analysis styles retain a 0.5-second
exponential trail measured in accepted audio time, so pausing freezes the field.
Seeking, signal gaps, style changes, and FFT size/window changes clear the trail.

The radial presentation is based on Noctalia Shell v5's
https://github.com/noctalia-dev/noctalia-shell/blob/e56a9db5/Widgets/AudioSpectrum/NMirroredSpectrum.qml[`NMirroredSpectrum.qml`],
not a pixel-identical port.

== Visual assets

`assets/rivu.svg` is the application icon; `assets/rivu.png` is its 256×256 export.
Album artwork is described in link:04_playback.adoc[Playback].

To regenerate the application icon PNG after editing the SVG source (requires
librsvg):

[source,sh]
----
rsvg-convert -w 256 -h 256 -o assets/rivu.png assets/rivu.svg
----
