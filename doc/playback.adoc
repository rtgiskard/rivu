= Playback

The Playback panel's buttons are Shuffle, Previous, Play/Pause, Next, and Repeat.
Shuffle and Repeat apply immediately; Repeat cycles Off, All, One. These are live
playback controls, separate from the unapplied draft in the settings dialog.
Previous restarts the current track when its position exceeds three seconds;
press it again near the start to select the previous queue entry.

The Playback panel shows artwork, elapsed/total time, seek, and volume controls.
Controls wrap in narrow panels. Seeking to the end follows normal queue completion;
if paused, playback remains paused until resumed. Previous restarts a track after
three seconds, otherwise it selects the previous queue entry.

The audio worker coalesces consecutive absolute seek commands already queued,
executing only the latest target in each batch of up to 64 seeks. It uses no
debounce window and does not wait for later input. Every non-seek audio command,
including pause, load, stop, and output settings, is an ordering barrier and stays
in sequence. A seek already executing is not cancelled; coalescing reduces
redundant decoder and output reopening rather than changing the seek pipeline.

Pause uses software gating and play counts use heard time confirmed by the output
backend. Recoverable output underruns do not start a new playback. Analysis pauses
while playback is paused; silent backend callbacks may still consume some CPU.
The audio worker waits for commands and backend events instead of polling unchanged
playback positions.

The TUI updates state while idle and redraws on state changes, local input, or
terminal resize. Up/Down and Enter operate on the selected queue occurrence;
Space toggles playback, `n`/`p` selects next/previous, and `q` exits only the TUI.

The GUI supports Space, `n`/`p`, Left/Right seeking, Home/End, `r` repeat,
`s` shuffle, and `[`/`]` volume. Up/Down and Enter operate on the focused Library
or Queue list; `d`/Delete removes selected queue occurrences. `q` closes the GUI
window without stopping the core. Text fields and popups take precedence.

Playlists support creation, renaming, deletion, import/export, playback, adding,
removing, and moving entries. If the next track cannot be opened after EOF,
playback stops and reports the error. Switching manually to a missing file does
not interrupt the current track. Removing tracks also removes their queue and
shuffle-history references.

== Native multichannel output

Speaker identities are preserved through decoding and resampling. On Linux, an
unset output device uses the default PipeWire sink; an explicit `PipeWire:
<node.name>` selects a named sink. Other explicit devices may use CPAL.

`pipewire_auto_mix` is enabled by default and lets PipeWire remix channels for
different sink layouts. Disable it to require a compatible speaker layout and
reject routes that would lose or remix channels. Unsupported layouts report an
error instead of silently downmixing.

== Extension audio decoding

Enable `ffmpeg_enabled` to play additional audio containers and codecs, including
audio tracks in MKV and MP4 files. Detection uses file contents, not only file
extensions. Corrupt streams and invalid layouts report errors.

The setting requires a binary built with Cargo's `ffmpeg` feature
(`cargo build --features ffmpeg`). In a default build, enabling it is rejected
as unavailable; native playback remains available. The extension supports
seeking and bounded decoder preroll.

Missing or incompatible FFmpeg libraries are reported in settings. FFmpeg is
not loaded when the extension is disabled.

`rivu quit`, the footer exit button, tray `Quit Rivu`, and MPRIS `Quit` stop the
core when their respective integration is enabled. Closing the GUI window leaves
the core and playback running; the tray is independent of MPRIS.

== Desktop queue

Queue rows represent occurrences, so repeated tracks can be selected and moved
independently. Click selects one row; Ctrl/Cmd toggles, Shift selects a range,
and double-click plays the selected occurrence. Right-clicking a selected row
keeps the selection.

The queue toolbar and menu support removal, moving, randomizing, deduplicating,
adding to playlists, and clearing the queue. Removing the current occurrence
stops playback; other removals leave playback running. Queue actions remain
available while the workspace is locked.

== Desktop album artwork

Rivu uses embedded front-cover artwork exposed by supported native media and does
not fetch images from the network. Unsupported or unavailable artwork falls back
to the bundled Rivu icon.

Artwork is cached below the selected data directory in `artwork/`; cache failures
do not prevent playback. MPRIS exposes the current artwork through `mpris:artUrl`.

== Runtime decoder dependencies

Native source builds do not require FFmpeg. The optional extension requires
FFmpeg 9 development headers (`libavutil` 61, `libavcodec` 63,
`libavformat` 63) and `libclang` on little-endian x86-64 or aarch64 Linux.
Other FFmpeg ABI major versions are rejected by `build.rs`. Runtime FFmpeg
libraries are loaded dynamically only when extension decoding is enabled.
